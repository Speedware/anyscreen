## Anyscreen Player (Android TV)

Native Android TV player for the [Anyscreen](https://github.com/Speedware/anyscreen) digital signage platform.

### Features
- Plays video (with or without audio), images, and websites from a playlist
- Seamless transitions between playlist items — content is prepared off-screen and revealed only when ready, so there's no black screen between items
- Works offline: caches assigned content locally and keeps playing on schedule even if the connection to the server drops
- Pairs to the dashboard with a 6-digit code shown full-screen on first launch
- Reports live status to the dashboard: online/offline, Wi-Fi signal strength or Ethernet, and what's currently playing
- Press Back on the remote at any time to reconfigure the server URL and re-pair
